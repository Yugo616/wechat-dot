# 暂存消息与安装包精简

用户要求：以一个小入口查看过期未发消息，支持单条、选中多条、全部恢复和一键清空；清空后不显示跳过数量。保持其他使用方式不变，同步 README 和 Mac ARM、Mac Intel、Windows 安装包。

## 方案

沿用当前队列和本地状态文件。主界面显示「N 条消息已暂存」和有边框的「查看」按钮；打开后在原窗口展示列表，不新增窗口或数据库。每条显示方向、时间、内容摘要和恢复按钮，下方提供恢复所选、全部恢复、清空。空列表不在主界面占位置。清空只移除暂存内容，保留去重凭据和聊天本身。

直接恢复旧数组里的任务，保留发送位置和请求 ID，避免复制任务引起重复发送。恢复时重新计时；保持原来的暂停／运行选择。未完成的 dot 回复先重新取完整内容，再转发。列表操作绑定当前账号组合和显示的记录，避免账号切换或新消息到达时误操作。

没有选择单独数据库或重写桌面框架：前者增加存储和迁移，后者会改变已经验证的登录、托盘和更新流程。本次保留 Electron 和独立浏览器，精简 Electron 的非中英文语言资源及打包资源，空轮询不再反复写相同状态。专用浏览器的语言、资料和启动方式不变。

## 验收

- 旧版本已经标记过期的消息可在新版本查看；重启后仍存在。
- 恢复单条、批量和全部；未选条目不动，已发送的回复片段不重发。
- 清空后数量消失，重启和重复收取不复现；账号、游标、正在处理的新消息不变。
- 暂停时恢复只入队；原有发送不确定状态继续核对，不能盲目重发。
- 缓存附件可恢复；未完成回复拿到完成内容后再发。
- 三平台检查、安装包、完整／差分更新通过，公开文件可下载；记录实际体积差值。
- README 用简短中文说明恢复／清空；不将模拟测试当作真实账号收发。
