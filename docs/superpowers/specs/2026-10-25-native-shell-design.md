# 原生窗口与小安装包

用户希望安装包只有几十 MB，同时保留已有使用方式。构建目标为 macOS arm64、macOS x64、Windows x64；账户、暂停状态、浏览器配置和暂存消息原地保留。

## 方案

继续裁剪 Electron 只能小幅减少体积。把 Electron 改成首次下载并没有减少实际依赖。采用 Tauri 系统 WebView 作为设置窗口，随包附带官方 Node 运行时，复用现有 TypeScript 转发代码和界面。这是实现选择；不要求用户安装开发环境或扩展。

ChatGPT 仍由现有独立 Chrome for Testing 打开，保留登录流程和浏览器隔离。该浏览器按需下载，磁盘占用单独说明，不冒充几十 MB 的总占用。

## 边界

- 提取现有主程序为共享控制器；Electron 入口保留为开发测试宿主，不随正式包分发。
- Rust 只负责窗口、托盘、单实例、尺寸和启动 Node。父子进程用标准输入输出传递请求及状态，不另开本地 HTTP 服务。
- 系统目录下沿用 `WeChat Dot` 数据目录。版本、路径、账号从配置及运行环境获取。
- 使用现有 electron-builder 安装包格式和更新源：Mac app/zip/dmg、Windows NSIS；继续校验下载并使用块映射差分，旧版可以直接升级。
- 窗口关闭仍最小化到托盘；退出弹窗和记住选择保留。崩溃或退出不能留下孤立转发进程。
- Windows 自动准备 WebView2；macOS 使用系统 WebKit。界面代码兼容系统 WebView。

## 验证

先构建仅包含原生窗口和官方 Node 的体积实验。成功后验证共享控制器、独立浏览器、文字/媒体/语音、暂存恢复/清空、暂停重启和更新；分别检查三种平台的安装包。Mac 实机检查原生窗口与已安装版本状态，真实账号消息不用于测试，原有暂停状态不变。
